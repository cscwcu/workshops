# 5 - Free Software

[Home](README.md)

In this section, we will talk about free tools that ourselves and other students in
the program use in our daily workflow. These tools help developers become more
efficient programmers, as they handle some of the the tedious headaches that can come with
programming. Thankfully, a large portion of industry-used programming software is completely
free, so you can get started on learning these now to help you in your time going through
the CS program. Additionally, many companies provide free trials of their software to students as long as they are actively enrolled in a university.

## 5.1 Visual Studio Code

An "all-in-one" IDE developed by Microsoft that is used by many students here in the CS
program. VS Code gives you a clean and easy to use customizable environment to write your
code in. Many free extensions are developed by first or third-party developers to fit your
needs for certain languages or situations. Any popular programming language will have an
offical extension built for VS Code. Other useful extensions include LiveShare, which
allows you to collaborate on code in real-time with a project partner, and the GitHub
extension, which allows you to interact with a GitHub repository directly from VS Code.

## 5.2 JetBrains

JetBrains is a company that develops a variety of tools that aid programmers in their
development, mainly consisting of IDE's. Our program teaches a lot of Java. Professors will mention IDEs like Eclipse or BlueJay for Java development, but JetBrains' Java IDE, IntelliJ, is a fan favorite of the CS program.

While VS Code is a "jack of all trades", each JetBrains IDE is heavily tailored to a specfic
programming language or field. Along with IntelliJ for Java, JetBrains also has PyCharm for Python and RustRover for Rust. These IDEs offer features like running code without compiling it, extensive debugging tools, and better code and syntax highlighting.

JetBrains IDEs have many of the same features VS Code extensions provide as built-in tools. The Code With Me tool is the equivalent to VS Code's LiveShare, while
JetBrains IDE's also have built-in GitHub integration.

JetBrains IDEs are paid products, but students can get a free license for as long as they are enrolled by signing up with their student email.

## 5.3 GitHub

GitHub is by far the best way to collaborate on a programming project with your team.
GitHub allows you to create a shared repository for your project and store those
files onto the repository, which is linked to your GitHub account. After making changes
to a project's files, you can easily push those changes to the repository, then your partner(s) can
pull those changes to instantly update their files. If you don't know how to use Git, GitHub
makes it very easy to at least learn the basics that would be used in a lower level class project.
There are also many great online tutorials that could quickly teach you the basics of Git and GitHub.

### 5.3. GitHub Student Developer Pack

GitHub offers a free pack of tools and services to students who are actively enrolled in a university. This pack includes free access to **GitHub Pro** and many other tools and services that can help you in your development workflow.

## 5.4 FileZilla/WinSCP

These two free softwares allow you to transfer files from your computer to a remote server. These programs
are very helpful with transferring files to and from Agora, which is a WCU-owned remote server that we
submit some of our projects to. These programs are easy to download and use. WinSCP is available only on
Windows, while FileZilla is available everywhere.

## 5.5 Grammarly

Grammarly is a tool that helps you write better by checking your grammar, punctuation, and style. It is available as a browser extension, a desktop app, and a mobile app. Grammarly can help you write better emails, essays, and code comments. It can also help you catch typos and other errors in your code.

Students of WCU get a free premium subscription to Grammarly. You can sign up for a free account using your student email address.
